# 0002 Industry-Standard Migration (July 2026)

## Status

Accepted.

## Context

Several schemas in this repository re-implemented, as bespoke JSON Schema
contracts, behavior that industry-standard tooling now provides directly:

- `scenario-manifest.v1` and `scenario-composition-manifest.v1` described a
  custom simulation-run configuration and composition format. `Hydra`
  (OmegaConf) config groups/defaults/overlays and ROS 2 Launch/Parameter
  files solve the same problem as a maintained, documented standard.
- `ros-graph-contract.v1` described expected ROS graph readiness
  (topics/services/actions) for a bespoke poller to check.
  `launch_testing_ros.WaitForTopics` is the ROS 2 upstream answer to the same
  need.
- `evidence-manifest.v1` and `run-metrics.v1` described a custom "did this
  run pass, and what did it measure" report format, with custom signing.
  `pytest --junitxml` plus SLSA Provenance attestations (generated by
  `slsa-framework/slsa-github-generator`) are the de-facto evidence standard
  for CI in 2026: JUnit XML is universally consumed by CI dashboards, and
  SLSA Provenance is an in-toto-based, cryptographically signed attestation
  format with broad tooling support (`slsa-verifier`, GitHub's own
  attestations UI), superior to a repository-local Cosign blob signature over
  a custom JSON shape.

## Decision

Remove `scenario-manifest.v1`, `scenario-composition-manifest.v1`,
`ros-graph-contract.v1`, `evidence-manifest.v1`, and `run-metrics.v1`
(schemas, fixtures, and packaged copies).

Keep every schema that encodes a business or security decision with no
generic standard replacement: `stack-lock.v1` (exact commit/digest pins),
`runtime-profile.v1`, `perception-provider.v1`, `model-artifact.v1`,
`artifact-store-policy.v1`, `domain-extension-manifest.v1`, and
`stack-compatibility.v1`.

## Consequences

Consumers (`robotics-simulation-harness`, `droning-simulation-infra`) adopt
`pytest` + `pytest-docker` + `launch_testing_ros` + `Hydra` +
`slsa-github-generator` directly instead of depending on this repository for
run configuration or evidence shape. This repository's surface area shrinks
to genuine cross-repo business contracts, which is also easier to keep
correct and versioned.
